## Description (en)

ZIKR is a calm, reliable counter for your daily practice. No ads, no sign-up, no internet.

COUNT WITHOUT LOOKING
• Action button on iPhone 15 Pro and later: one press, plus one.
• Lock Screen and Dynamic Island: count with a + button without unlocking.
• Interactive widget and a Control Center control.
• Back Tap via Shortcuts.
• Night mode: a black screen where the whole display is the button, and it never locks.

MULTI-STEP PROGRAMS
Build your own sequence such as 33 + 33 + 34. ZIKR moves to the next step automatically, marks completion with a strong haptic, and remembers progress even if you close the app. You name every step.

HONEST STATISTICS
• Taps per day, a six-month heatmap and streaks.
• Gentle streaks: one missed day a week does not break them.
• Carried-over starting numbers and manual corrections never count as taps.

RELIABLE
• Data stays on your iPhone and in its iCloud backup.
• A daily automatic copy for the last 7 days, plus file export and import.
• Undo the last tap — even if it was yesterday.

ALSO
• Overall goal, daily goal, and a signal every N taps.
• Reminders by weekday. Stopwatch.
• Russian, Uzbek (Latin and Cyrillic) and English.
• Light and dark appearance, Dynamic Type, VoiceOver.

## Notes for App Review

```
ZIKR is a private, offline counter. Key features to review:
1. Count tab: tap the large ring to add one. "Night mode" button opens a black full-screen counter.
2. "Lock Screen" button starts a Live Activity; the + button on the Lock Screen/Dynamic Island adds one.
3. Settings → "Count without looking" explains the Action button (Controls → "ZIKR +1"),
   Back Tap, Control Center control and the interactive widget.
4. List tab → + → "New program" creates a multi-step sequence that advances automatically.
No account, no network access, no data collection. All content (names, notes) is written by the user.
```
